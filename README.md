# shortcut
### 키보드 단축키를 배우는 웹 게임

---

## 프로젝트 소개

---

## 주요 기능

- 키보드를 이용한 단축키 입력
- 다양한 단축키 문제 출제
- 단축키 학습
- 제한 시간 시스템
- 정답/오답 판정
- 점수 시스템
- 게임 재시작/틀린문제만 풀기
- 게임 결과

---

## 기술 스택

- HTML5
- CSS3
- JavaScript
